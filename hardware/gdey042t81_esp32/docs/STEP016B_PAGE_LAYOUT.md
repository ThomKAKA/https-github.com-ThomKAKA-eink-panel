字段映射见 [JSON Schema](STEP016B_JSON_SCHEMA.md)。现有右侧标题实现仍为“改确认页位置”；未来普通业务路径改用 current_step，不能在当前尚未改代码时声称已生效。既有等待/错误语义仍保留，不自动发布无效输入。
既有标题大写规则、百分比自适应缩小和字号体系8/10/13/18/24/最大64保持；外框、横向分栏和终端风不重新设计。source/time 起点不是字形包围盒保证。
中文字体在 PC 解析与渲染，记录实际文件与哈希；不能仅凭字体名称保证缺字不存在。必须检查所用字符覆盖、文本边界、重叠及1-bit预览可读性。
缺字、溢出或不可读阻止产物放行；现有 draw.text 不提供所有长文本适配保证。不能以“渲染调用成功”或按字符数截断替代视觉验收。第一版超出布局容量时拒绝候选，不默默改布局。
所有区域共同组成全屏刷新，不定义局刷窗口或区域更新周期。时间为快照标签，不走时。

## 方向契约

定义三个独立坐标系，均为400×300：

| 坐标系 | 定义 |
| --- | --- |
| L | 正常可读的页面逻辑帧，也是 progress.preview.png |
| T | 导出后用于 raw/header 的传输帧 |
| P | 正视物理面板，FPC 朝下，左上为原点 |

```text
T(x,y) = L(x,299-y)             PC 导出预翻转一次
P(x,y) = T(x,299-y) = L(x,y)    固定 H1 mirror_y=true
```

保持 H1 输入位图→面板 Y mirror 历史结论；不是把 H1 改成 identity。预览不得误用 T 方向，ESP32 不得再反转一次。禁止额外 rotation、隐式图像方向处理或重复行逆序。
像素打包先明确 T 的行序，再使用 row-major/MSB-first 编码；不能混淆字节位序反转与 Y 行反转。
组合恒等是设计/软件测试目标，仍需未来正常中文和非对称角标实机确认，不声称所有像素已经验证。对应 [测试矩阵](STEP016B_TEST_PLAN.md)。
