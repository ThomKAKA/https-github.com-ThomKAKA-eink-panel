# 本地 1-bit 测试帧

`src/test_frame.h` 用 C++17 constexpr 生成两张 400×300 raw MONO1 位图，各 15,000 字节。
它们编译成只读数据，不提交 PNG/BMP/二进制资源，不要求运行 Python 生成器，也不使用运行时堆分配。
GxEPD2 另有一个 15,000 字节全屏绘图缓冲；实际 RAM/Flash 占用必须以将来的编译报告为准。

Frame A 包含：

- 四边 1 像素黑框；检查 400×300 是否缺边或裁剪。
- 四个不同的角标，便于发现旋转或镜像。
- 从 (40,40) 开始的斜线，以及底部 8 像素黑白条。
- (7,60) 与 (8,61) 的跨字节探针；按 MSB first 解释。

Frame B 只增加中央 `(180,130)` 起的 `40×30` 黑块。
默认 H1 只显示 A 并保持；显式启用有限刷新演示才在 A/B 间切换。

逻辑位序/尺寸可由 `tests/test_core.cpp` 检查；1:1 物理坐标、方向、极性及残影必须目视实测。
普通 BMP 导出文件不能直接作为此位图指针。
