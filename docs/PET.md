# 宠物页（P7）

> 静态宠物状态页：每天或每次互动后换一帧，不做动画，设备端不存状态。

## 形象

- 用户提供的线稿模板：`assets/pet/source.webp`（右下角带“豆包 AI 生成”水印）。
- `scripts/prepare_pet_art.py` 把模板裁到人物、缩放到 174×186、按 192 阈值二值化，
  输出 `assets/pet/chibi.png`。水印在裁剪窗口之外，不进入画面。
- 面板把这张 1-bit 位图原样贴在 (16, 56)，**不重绘、不改表情**；状态只通过右侧文字和
  三条状态条表达。换图就替换 `source.webp` 后重跑脚本。

## 文档（`data/pages/pet.json`）

| 字段 | 含义 |
| --- | --- |
| `name` | 1–8 字，默认「大肥鱼」 |
| `satiety` | 0–100，写入日（`updated_at` 所在日）的饱食 |
| `mood` | 0–100 |
| `affinity` | 0–999，等级 = min(99, 1 + affinity // 25) |
| `last_fed` | `YYYY-MM-DD`，只用于「今天已喂 / 今天还没喂」 |
| `last_interaction` | `YYYY-MM-DD HH:MM` |

## 每日衰减

以 `updated_at` 的日期为基准，渲染日与基准日相差 `days` 天：

- `decay = 0`（当天）；否则 `25 + 15 × (days − 1)`（隔 1 天 25，隔 3 天 55……）。
- 有效饱食 `= max(0, satiety − decay)`；有效饱食 < 30 时心情再 `−10`。
- 同文档 + 同 `day_key` 渲染字节相同；跨过零点自动出新帧，不需要定时写文档。

每次互动都基于**有效值**计算，写回后 `updated_at` 变成当天，等于把衰减基准重置，
不会重复扣减。

## 互动

| 动作 | 效果 | 说明 |
| --- | --- | --- |
| 喂食 `feed` | 饱食 +30、亲密 +2、`last_fed` = 今天 | 上限 100 / 999 |
| 摸摸 `pet` | 心情 +12、亲密 +1 | 上限 100 / 999 |
| 玩耍 `play` | 心情 +20、饱食 −10、亲密 +3 | 下限 0，上限 100 / 999 |

- `POST /api/pet/interact`，请求体 `{"action": "feed" | "pet" | "play"}`；未知动作 422。
- 每次成功写入 revision + 1；并发冲突重试一次，仍冲突返回 409。
- `GET /api/pet/state` 返回今天视角的有效值（名字、等级、饱食/心情/亲密、是否已喂、
  上次互动），供 `/manage` 显示。
- `GET /api/pages/pet` 读原始文档；`PUT` 返回 400 `Page is read-only`；
  `POST /api/pages/pet/preview` 用仓内文档 + 今天日期渲染，忽略请求体。

## 屏幕

- 页头「宠物 PET」+ 日期星期；左侧位图；右侧名字、`Lv.N`、饱食/心情/亲密三条 10 px 粗体
  标签和数值、`很饱 · 开心` 一类的状态词、「今天已喂 / 今天还没喂」、上次互动。
- 页脚 10 px 黑体：`来源 / pet rN`、`更新 / …`；从未互动写「等待互动」。
- 一帧 15000 B `epd-t-400x300-mono1-msb-v1`；内容变化才刷新，未变化 304。

## 限制

- 只有一个固定形象；改图要替换模板并重跑脚本，页面上不能换。
- 不做动画、不做离线宠物、不在设备端存数据。
- 跨日衰减只在 Host 渲染时体现；Host 不在线时设备停在最后一帧。
- 位图是 174×186 的二值化版本，细节比原图少；1-bit 面板上以轮廓为主。
