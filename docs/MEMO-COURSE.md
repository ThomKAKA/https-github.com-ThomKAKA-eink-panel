# Memo 与 Course 语义（P4）

> 本文件定义两页的最终语义，代码与测试以这里为准。

## Memo（备忘录）

- 最多 8 项。每项：`id`（`A-Za-z0-9_-`，1–32）、`text`（1–60 字）、`face`
  （`todo` / `doing` / `done` / `note`）、可选 `due`。
- `due` 在存储中精确到分钟（`YYYY-MM-DD HH:MM`），用于排序；**屏幕只显示日级状态**：
  `OVERDUE`（已过期）、`TODAY`（今天）、`LATER`（以后），并附 `MM-DD`。
- 明确不做分钟级倒计时，也不显示剩余小时/分钟；这是墨水屏刷新代价下的定稿语义。
- **不支持 emoji**：渲染管线是 1-bit 单色并带缺字审计，emoji 字形不在系统字体中会导致
  渲染被拒绝。编辑器仍允许输入，但请只用文字、数字和常见符号。

## Course（课表）

### 固定 5 节次

| 节次 | 时间 |
| --- | --- |
| 第 1 节 | 08:00–09:40 |
| 第 2 节 | 10:00–11:40 |
| 第 3 节 | 14:00–15:40 |
| 第 4 节 | 16:00–17:40 |
| 第 5 节 | 19:00–20:40 |

- 每门课属于一个节次（`period` 1–5）、一个星期（1–7）、若干周次（1–30）和一个教室。
- 同一星期、同一周次、同一节次只能有一门课；写入时校验，冲突返回 422。
- 最多 12 门课程、16 条调课。

### 按日期调整

调课按日期生效，动作有四种：

- `cancel`：当天取消这门课。
- `move_room`：当天换教室（只填教室）。
- `move_period`：当天换到另一个节次（只填节次）。
- `add`：临时新增一节课（课程名、节次、教室）；每天最多 1 节，且新增课程的标识不能与已有
  课程重复。临时课只在该日期出现，不进入周模板。

### 屏幕

- 当天视图最多 5 门常规课 + 1 节临时课（共 6 行）；每行显示
  `第N节 HH:MM–HH:MM`、课程名（自动缩放不截断）和教室。
- 学期外与无课分别显示「学期外」「今天没有课」；页脚为 10 px 加粗的
  `来源 / course rN` 与 `更新 / ...`。
- 日期与门数使用 10 px 加粗，避免 8 px 在真机上发虚。

## 数据兼容

旧课表文档使用任意的 `start`/`end`，新模型不再接受。本机保存的旧文档已按「最近的节次开始
时间」改写为固定节次（09:00 归入第 1 节，14:00 归入第 3 节）；其他环境的旧文档需要重新保存
一次课表。
