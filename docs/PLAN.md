# Development Plan

## Active scope: Phase 3

The current milestone delivers one browser-based 400×300 three-panel simulator:

- shared monochrome design tokens;
- `BasePanel` and `progress`, `stats`, and `flow` factory entries;
- compact ProgressPanel, StatsPanel, and FlowPanel rendering;
- Normal and 1-bit E-Ink previews;
- PNG and BMP export;
- per-panel example, waiting, and invalid-data states;
- Mock, Local JSON, and HTTP JSON adapters;
- manual and opt-in automatic refresh;
- in-memory Last Known Good fallback and lightweight source status;
- tests and beginner-oriented setup instructions.

Implementation stops after Phase 3 for approval. Account-backed APIs, private tokens,
databases, AI integration, ESP32 firmware, and hardware work are explicitly deferred.
