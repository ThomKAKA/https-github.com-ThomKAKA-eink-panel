# R6 LAN OTA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add explicit, one-shot LAN OTA to the ESP32-M1 with a credential-free image, SHA-256/image validation, and a 120-second boot self-test before rollback acceptance.

**Architecture:** The Host loads one local firmware file at startup and exposes status, manifest, image, arm and disarm endpoints. The device keeps its pull-only loop: before each frame transaction it checks the manifest; only an armed, version-changing offer starts a streamed OTA write to the next app partition. The machine remains hardware-free/testable through `Port`; esp_ota and mbedTLS live in a sink adapter. The new image is marked valid only after 120 seconds of continuous Wi-Fi.

**Tech Stack:** Python 3.14 / FastAPI 0.116 / pytest; vanilla ES modules / Node `node --test`; Arduino-ESP32 2.0.17 / ESP-IDF 4.4.7 / PlatformIO 6.12; esp_ota_ops + mbedTLS.

**Spec:** `docs/superpowers/specs/2026-11-07-r6-lan-ota-design.md`

## Global Constraints

- Trusted LAN only. No HTTPS, authentication, signed images, cloud, upload UI or delta OTA.
- Never write, log, serve or commit a real Wi-Fi SSID/password, token or credential. The OTA image is built with `EINK_OTA_BUILD=1` and contains no private Wi-Fi configuration.
- No NVS erase, full-chip erase, partition-table change or display call during OTA.
- No frame publish during R6 tests. No physical reset or USB upload without a separate explicit confirmation.
- One-shot arm, 600-second expiry, no automatic retry. Successful version report auto-disarms.
- Manifest/image bodies and header order are frozen by the spec; do not add fields.
- Preserve existing state numeric values 0..17; append `FirmwareCheck=18`, `FirmwareUpdate=19`.
- Every code change starts with a failing test; run the named command and observe the failure before implementing.
- Do not commit `config/firmware.json`, firmware binaries, private headers or credentials.

```python
"""Process-local, one-image LAN OTA offer. No path or credential is exposed."""

from __future__ import annotations

import hashlib
import json
import logging
import re
from dataclasses import dataclass
from datetime import datetime, timedelta, timezone
from pathlib import Path
from threading import Lock

logger = logging.getLogger(__name__)

MAX_FIRMWARE_BYTES = 1_200_000
ARM_SECONDS = 600
_VERSION = re.compile(r"^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$")


@dataclass(frozen=True)
class FirmwareImage:
    version: str
    size: int
    sha256: str
    body: bytes


class FirmwareOffer:
    """One configured image, one one-shot arm, all state process-local."""

    def __init__(self, config_path: Path, root: Path, *, clock=None) -> None:
        self._config_path = Path(config_path)
        self._root = Path(root)
        self._clock = clock or (lambda: datetime.now(timezone.utc))
        self._lock = Lock()
        self._image: FirmwareImage | None = None
        self._armed = False
        self._expires_at: datetime | None = None
        self._served_at: datetime | None = None
        self._device_version: str | None = None
        self._load()

    def _load(self) -> None:
        try:
            payload = json.loads(self._config_path.read_text(encoding="utf-8"))
            version = payload["version"]
            path = Path(payload["path"])
            if not path.is_absolute():
                path = self._root / path
            if not isinstance(version, str) or not _VERSION.fullmatch(version):
                raise ValueError("invalid version")
            if not path.is_file():
                raise ValueError("invalid image path")
            body = path.read_bytes()
            if not 1 <= len(body) <= MAX_FIRMWARE_BYTES:
                raise ValueError("invalid image size")
            image = FirmwareImage(version, len(body), hashlib.sha256(body).hexdigest(), body)
            self._image = image
            logger.info(
                "Firmware offer ready: version=%s size=%d sha256=%s",
                image.version,
                image.size,
                image.sha256[:12],
            )
        except (OSError, ValueError, KeyError, TypeError, json.JSONDecodeError):
            self._image = None
            logger.warning("Firmware offer unavailable; OTA disabled")

    @property
    def configured(self) -> bool:
        return self._image is not None

    def _now(self) -> datetime:
        value = self._clock()
        return value if value.tzinfo else value.replace(tzinfo=timezone.utc)

    def _expire_locked(self, now: datetime) -> None:
        if self._armed and self._expires_at is not None and now >= self._expires_at:
            self._armed = False
            self._expires_at = None

    def status(self) -> dict:
        with self._lock:
            now = self._now()
            self._expire_locked(now)
            image = self._image
            return {
                "configured": image is not None,
                "armed": self._armed,
                "version": image.version if image else None,
                "size": image.size if image else None,
                "sha256": image.sha256 if image else None,
                "expires_at": self._expires_at.isoformat() if self._expires_at else None,
                "served_at": self._served_at.isoformat() if self._served_at else None,
                "device_version": self._device_version,
            }

    def manifest(self) -> dict | None:
        with self._lock:
            image = self._image
            if image is None:
                return None
            now = self._now()
            self._expire_locked(now)
            if not self._armed:
                return {"armed": False}
            return {
                "armed": True,
                "version": image.version,
                "size": image.size,
                "sha256": image.sha256,
            }

    def arm(self) -> bool:
        with self._lock:
            if self._image is None:
                return False
            self._armed = True
            self._expires_at = self._now() + timedelta(seconds=ARM_SECONDS)
            self._served_at = None
            return True

    def disarm(self) -> None:
        with self._lock:
            self._armed = False
            self._expires_at = None

    def take_image(self) -> FirmwareImage | None:
        with self._lock:
            image = self._image
            if image is None:
                return None
            now = self._now()
            self._expire_locked(now)
            if not self._armed:
                return None
            self._armed = False
            self._expires_at = None
            self._served_at = now
            return image

    def observe_device_version(self, version: str) -> None:
        with self._lock:
            self._device_version = version
            if self._image is not None and version == self._image.version:
                self._armed = False
                self._expires_at = None
```

```cpp
#include "protocol.h"

namespace eink::network_progress {
constexpr const char* kOtaManifestEndpoint = "/api/device/firmware/manifest";
constexpr const char* kOtaImageEndpoint = "/api/device/firmware/image";
constexpr size_t kOtaManifestBytes = 512;
constexpr size_t kOtaHeaderBytes = 2048;
constexpr size_t kOtaLineBytes = 512;
constexpr uint32_t kOtaMaxImageBytes = 1200000;

struct FirmwareOffer {
  bool armed;
  char version[65];
  char sha256[65];
  uint32_t size;
};

inline bool validVersion(const char* value) {
  if (!value) return false;
  const size_t n = std::strlen(value);
  if (n < 1 || n > 64) return false;
  for (size_t i = 0; i < n; ++i) {
    const char c = value[i];
    if (i == 0 && !((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') || (c >= '0' && c <= '9'))) return false;
    if (!((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') ||
          (c >= '0' && c <= '9') || c == '.' || c == '_' || c == '-')) return false;
  }
  return true;
}

inline bool validSha256(const char* value) {
  if (!value || std::strlen(value) != 64) return false;
  for (size_t i = 0; i < 64; ++i)
    if (!((value[i] >= '0' && value[i] <= '9') || (value[i] >= 'a' && value[i] <= 'f'))) return false;
  return true;
}

inline bool parseManifestBody(const char* body, FirmwareOffer& out) {
  out = FirmwareOffer{};
  if (!body) return false;
  if (!std::strcmp(body, "{\"armed\":false}")) return true;
  char version[65]{}, sha[65]{};
  unsigned size = 0;
  if (std::sscanf(body,
      "{\"armed\":true,\"version\":\"%64[^\"]\",\"size\":%u,\"sha256\":\"%64[0-9a-f]\"}",
      version, &size, sha) != 3) return false;
  if (!validVersion(version) || !validSha256(sha) || size == 0 ||
      size > kOtaMaxImageBytes) return false;
  char expected[kOtaManifestBytes];
  const int n = std::snprintf(expected, sizeof(expected),
    "{\"armed\":true,\"version\":\"%s\",\"size\":%u,\"sha256\":\"%s\"}",
    version, size, sha);
  if (n <= 0 || size_t(n) >= sizeof(expected) || std::strcmp(expected, body)) return false;
  out.armed = true;
  out.size = size;
  std::memcpy(out.version, version, sizeof(version));
  std::memcpy(out.sha256, sha, sizeof(sha));
  return true;
}

struct ImageHeaders {
  uint32_t length;
  char version[65];
  char sha256[65];

  uint32_t length;

  void reset() { *this = ManifestHeaderParser{}; }
  bool feed(uint8_t c) {
    if (done_ || bad_ || ++total_ > kOtaHeaderBytes || ++lineUsed_ > kOtaLineBytes) return fail();
    if (cr_) {
      if (c != '\n') return fail();
      cr_ = false;
      const bool ok = line(View(line_, used_));
      used_ = lineUsed_ = 0;
      return ok;
    }
    if (c == '\r') { cr_ = true; return true; }
    if (c == '\n' || c == 0 || (c < 32 && c != '\t') || c >= 127) return fail();
    if (used_ >= sizeof(line_)) return fail();
    line_[used_++] = char(c);
    return true;
  }
  bool done() const { return done_; }
  const ManifestHeaders& headers() const { return headers_; }
 private:
  bool fail() { bad_ = true; return false; }
  bool line(View v) {
    if (!status_) {
      if (v.size() < 13 || !(v.substr(0, 9) == "HTTP/1.1 " || v.substr(0, 9) == "HTTP/1.0 ")) return false;
      if (v.substr(9, 3) != "200") return false;
      status_ = 200;
      return true;
    }
    if (v.empty()) {
      if (seen_ != 7u) return false;
      done_ = true;
      return true;
    }
    const auto colon = v.find(':');
    if (colon == View::npos || colon == 0) return false;
    for (char c : v.substr(0, colon)) if (!token(c)) return false;
    const View name = v.substr(0, colon);
    const View value = trim(v.substr(colon + 1));
    if (equalCI(name, "Transfer-Encoding") || equalCI(name, "Content-Encoding")) return false;
    auto unique = [&](unsigned bit) { if (seen_ & bit) return false; seen_ |= bit; return true; };
    if (equalCI(name, "Content-Type")) {
      return unique(1u << 0) && equalCI(value, "application/json");
    }
    if (equalCI(name, "Content-Length")) {
      if (!unique(1u << 1) || value.empty()) return false;
      uint32_t n = 0;
      for (char c : value) {
        if (c < '0' || c > '9' || n > kOtaManifestBytes / 10) return false;
        n = n * 10 + uint32_t(c - '0');
      }
      if (n == 0 || n > kOtaManifestBytes) return false;
      headers_.length = n;
      return true;
    }
    if (equalCI(name, "Connection")) {
      return unique(1u << 2) && equalCI(value, "close");
    }
    return true;
  }

  size_t used_ = 0, lineUsed_ = 0, total_ = 0;

 public:
  void reset() { *this = ImageHeaderParser{}; }
  bool feed(uint8_t c) {
    if (done_ || bad_ || ++total_ > kOtaHeaderBytes || ++lineUsed_ > kOtaLineBytes) return fail();
    if (cr_) {
      if (c != '\n') return fail();
      cr_ = false;
      const bool ok = line(View(line_, used_));
      used_ = lineUsed_ = 0;
      return ok;
    }
    if (c == '\r') { cr_ = true; return true; }
    if (c == '\n' || c == 0 || (c < 32 && c != '\t') || c >= 127) return fail();
    if (used_ >= sizeof(line_)) return fail();
    line_[used_++] = char(c);
    return true;
  }
  bool done() const { return done_; }
  const ImageHeaders& headers() const { return headers_; }
 private:
  bool fail() { bad_ = true; return false; }
  static bool copyValue(View value, char (&out)[65]) {
    if (value.size() > 64) return false;
    std::memcpy(out, value.data(), value.size());
    out[value.size()] = 0;
    return true;
  }
  bool line(View v) {
    if (!status_) {
      if (v.size() < 13 || !(v.substr(0, 9) == "HTTP/1.1 " || v.substr(0, 9) == "HTTP/1.0 ")) return false;
      if (v.substr(9, 3) != "200") return false;
      status_ = 200;
      return true;
    }
    if (v.empty()) {
      constexpr unsigned required = 63u;
      if (seen_ != required) return false;
      done_ = true;
      return true;
    }
    const auto colon = v.find(':');
    if (colon == View::npos || colon == 0) return false;
    for (char c : v.substr(0, colon)) if (!token(c)) return false;
    const View name = v.substr(0, colon);

      if (!unique(1u << 0) || !equalCI(value, "application/octet-stream")) return false;
      return true;
    }
    if (equalCI(name, "Content-Length")) {
      if (!unique(1u << 1) || value.empty()) return false;

        n = n * 10 + uint32_t(c - '0');

    }

      if (!unique(1u << 5) || !equalCI(value, "close")) return false;
      return true;
    }
    return true;
  }
  char line_[kOtaLineBytes]{};
  size_t used_ = 0, lineUsed_ = 0, total_ = 0;
  unsigned seen_ = 0;
  int status_ = 0;
  bool cr_ = false, done_ = false, bad_ = false;
```

Create `ota.h`:

```cpp
#pragma once
#include "machine.h"
#include "host_resolution.h"
#include "ota_protocol.h"
#include <algorithm>
#include <cstdio>
#include <cstring>

namespace eink::network_progress {
class OtaSink {
 public:
  virtual ~OtaSink() = default;
  virtual bool begin(size_t size) = 0;
  virtual bool write(const uint8_t* data, size_t size) = 0;
  virtual bool finish(const char* expectedSha) = 0;
  // Sets the next boot partition and logs NETWORK_OTA_READY once it succeeds.
  virtual bool activate(const char* version) = 0;
  virtual void abort() = 0;
};

class OtaUpdater {
 public:
  OtaUpdater(Port& port, const ResolvedHost& host, OtaSink& sink)
      : port_(port), host_(host), sink_(sink) {}

  FirmwareCheckResult beginCheck() {
    if (active_) return FirmwareCheckResult::InvariantFailure;
    const int n = std::snprintf(request_, sizeof(request_),
      "GET %s HTTP/1.1\r\nHost: %u.%u.%u.%u:%u\r\nConnection: close\r\n"
      "Accept: application/json\r\n\r\n",
      kOtaManifestEndpoint, host_.address[0], host_.address[1],
      host_.address[2], host_.address[3], host_.port);
    if (n <= 0 || size_t(n) >= sizeof(request_)) return FirmwareCheckResult::InvariantFailure;
    resetTransfer(size_t(n));
    phase_ = Phase::ManifestHeaders;
    const auto result = port_.beginTcp();
    if (result == ConnectResult::InvariantFailure) return finishCheck(FirmwareCheckResult::InvariantFailure);
    if (result == ConnectResult::Failed) return finishCheck(FirmwareCheckResult::Failed);
    tcpOpen_ = true;
    connected_ = result == ConnectResult::Connected;
    return FirmwareCheckResult::Pending;
  }

  FirmwareCheckResult pollCheck() {
    if (!active_ || (phase_ != Phase::ManifestHeaders && phase_ != Phase::ManifestBody))
      return FirmwareCheckResult::InvariantFailure;
    if (!connected_) {
      if (expired(port_.now(), start_, 3000) || !port_.connected())
        return finishCheck(FirmwareCheckResult::Failed);
      const auto result = port_.pollTcp();
      if (result == ConnectResult::InvariantFailure) return finishCheck(FirmwareCheckResult::InvariantFailure);
      if (result == ConnectResult::Failed) return finishCheck(FirmwareCheckResult::Failed);
      connected_ = result == ConnectResult::Connected;
      return FirmwareCheckResult::Pending;
    }
    const uint32_t now = port_.now();
    if (expired(now, start_, 5000) || expired(now, idle_, 2000))
      return finishCheck(FirmwareCheckResult::Failed);
    if (sent_ < requestSize_) {
      const int n = port_.send(reinterpret_cast<const uint8_t*>(request_) + sent_, requestSize_ - sent_);
      if (n == kIoInvariant) return finishCheck(FirmwareCheckResult::InvariantFailure);
      if (n == kIoPending) return FirmwareCheckResult::Pending;
      if (n <= 0) return finishCheck(FirmwareCheckResult::Failed);
      if (size_t(n) > requestSize_ - sent_) return finishCheck(FirmwareCheckResult::InvariantFailure);
      sent_ += size_t(n);
      return FirmwareCheckResult::Pending;
    }
    if (phase_ == Phase::ManifestHeaders) {
      uint8_t byte = 0;
      const int n = port_.receive(&byte, 1);
      if (n == kIoInvariant) return finishCheck(FirmwareCheckResult::InvariantFailure);
      if (n == kIoPending) return FirmwareCheckResult::Pending;
      if (n != 1) return finishCheck(FirmwareCheckResult::Failed);
      idle_ = now;
      if (!manifestHeaders_.feed(byte)) return finishCheck(FirmwareCheckResult::Failed);
      if (manifestHeaders_.done()) {
        bodyLength_ = manifestHeaders_.headers().length;
        bodyUsed_ = 0;
        phase_ = Phase::ManifestBody;
      }
      return FirmwareCheckResult::Pending;
    }
    if (bodyUsed_ < bodyLength_) {
      const size_t amount = bodyLength_ - bodyUsed_;
      const int n = port_.receive(reinterpret_cast<uint8_t*>(checkBody_ + bodyUsed_), amount);
      if (n == kIoInvariant) return finishCheck(FirmwareCheckResult::InvariantFailure);
      if (n == kIoPending) return FirmwareCheckResult::Pending;
      if (n <= 0 || size_t(n) > amount) return finishCheck(FirmwareCheckResult::Failed);
      bodyUsed_ += size_t(n);
      idle_ = now;
      if (bodyUsed_ < bodyLength_) return FirmwareCheckResult::Pending;
    }
    uint8_t excess = 0;
    const int n = port_.receive(&excess, 1);
    if (n == kIoInvariant) return finishCheck(FirmwareCheckResult::InvariantFailure);
    if (n == kIoPending) return FirmwareCheckResult::Pending;
    if (n != 0) return finishCheck(FirmwareCheckResult::Failed);
    if (!closeSocket()) return finishCheck(FirmwareCheckResult::InvariantFailure);
    checkBody_[bodyUsed_] = 0;
    FirmwareOffer offer{};
    if (!parseManifestBody(checkBody_, offer)) return finishCheck(FirmwareCheckResult::Failed);
    if (!offer.armed || !std::strcmp(offer.version, port_.firmwareVersion()))
      return finishCheck(FirmwareCheckResult::NoUpdate);
    offer_ = offer;
    return finishCheck(FirmwareCheckResult::UpdateAvailable);
  }

  FirmwareUpdateResult beginUpdate() {
    if (active_ || !offer_.armed) return FirmwareUpdateResult::Failed;
    if (!sink_.begin(offer_.size)) return FirmwareUpdateResult::Failed;
    const int n = std::snprintf(request_, sizeof(request_),
      "GET %s HTTP/1.1\r\nHost: %u.%u.%u.%u:%u\r\nConnection: close\r\n"
      "Accept: application/octet-stream\r\nAccept-Encoding: identity\r\n\r\n",
      kOtaImageEndpoint, host_.address[0], host_.address[1],
      host_.address[2], host_.address[3], host_.port);
    if (n <= 0 || size_t(n) >= sizeof(request_)) {
      sink_.abort();
      return FirmwareUpdateResult::Failed;
    }
    resetTransfer(size_t(n));
    phase_ = Phase::ImageHeaders;
    const auto result = port_.beginTcp();
    if (result == ConnectResult::InvariantFailure) {
      sink_.abort();
      return FirmwareUpdateResult::InvariantFailure;
    }
    if (result == ConnectResult::Failed) {
      sink_.abort();
      return FirmwareUpdateResult::Failed;
    }
    tcpOpen_ = true;
    connected_ = result == ConnectResult::Connected;
    return FirmwareUpdateResult::Pending;
  }

  FirmwareUpdateResult pollUpdate() {
    if (!active_ || (phase_ != Phase::ImageHeaders && phase_ != Phase::ImageBody))
      return FirmwareUpdateResult::InvariantFailure;
    if (!connected_) {
      if (expired(port_.now(), start_, 3000) || !port_.connected())
        return finishUpdate(FirmwareUpdateResult::Failed);
      const auto result = port_.pollTcp();
      if (result == ConnectResult::InvariantFailure) return finishUpdate(FirmwareUpdateResult::InvariantFailure);
      if (result == ConnectResult::Failed) return finishUpdate(FirmwareUpdateResult::Failed);
      connected_ = result == ConnectResult::Connected;
      return FirmwareUpdateResult::Pending;
    }
    const uint32_t now = port_.now();
    if (expired(now, start_, 120000) || expired(now, idle_, 10000))
      return finishUpdate(FirmwareUpdateResult::Failed);
    if (sent_ < requestSize_) {
      const int n = port_.send(reinterpret_cast<const uint8_t*>(request_) + sent_, requestSize_ - sent_);
      if (n == kIoInvariant) return finishUpdate(FirmwareUpdateResult::InvariantFailure);
      if (n == kIoPending) return FirmwareUpdateResult::Pending;
      if (n <= 0) return finishUpdate(FirmwareUpdateResult::Failed);
      if (size_t(n) > requestSize_ - sent_) return finishUpdate(FirmwareUpdateResult::InvariantFailure);
      sent_ += size_t(n);
      return FirmwareUpdateResult::Pending;
    }
    if (phase_ == Phase::ImageHeaders) {
      uint8_t byte = 0;
      const int n = port_.receive(&byte, 1);
      if (n == kIoInvariant) return finishUpdate(FirmwareUpdateResult::InvariantFailure);
      if (n == kIoPending) return FirmwareUpdateResult::Pending;
      if (n != 1) return finishUpdate(FirmwareUpdateResult::Failed);
      idle_ = now;
      if (!imageHeaders_.feed(byte)) return finishUpdate(FirmwareUpdateResult::Failed);
      if (imageHeaders_.done()) {
        const auto& h = imageHeaders_.headers();
        if (h.length != offer_.size ||
            std::strcmp(h.version, offer_.version) ||
            std::strcmp(h.sha256, offer_.sha256))
          return finishUpdate(FirmwareUpdateResult::Failed);
        bodyLength_ = offer_.size;
        bodyUsed_ = 0;
        phase_ = Phase::ImageBody;
      }
      return FirmwareUpdateResult::Pending;
    }
    if (bodyUsed_ < bodyLength_) {
      const size_t amount = std::min(sizeof(otaBuffer_), bodyLength_ - bodyUsed_);
      const int n = port_.receive(otaBuffer_, amount);
      if (n == kIoInvariant) return finishUpdate(FirmwareUpdateResult::InvariantFailure);
      if (n == kIoPending) return FirmwareUpdateResult::Pending;
      if (n <= 0 || size_t(n) > amount) return finishUpdate(FirmwareUpdateResult::Failed);
      if (!sink_.write(otaBuffer_, size_t(n))) return finishUpdate(FirmwareUpdateResult::Failed);
      bodyUsed_ += size_t(n);
      idle_ = now;
      return FirmwareUpdateResult::Pending;
    }
    uint8_t excess = 0;
    const int n = port_.receive(&excess, 1);
    if (n == kIoInvariant) return finishUpdate(FirmwareUpdateResult::InvariantFailure);
    if (n == kIoPending) return FirmwareUpdateResult::Pending;
    if (n != 0) return finishUpdate(FirmwareUpdateResult::Failed);
    if (!closeSocket()) return finishUpdate(FirmwareUpdateResult::InvariantFailure);
    if (!sink_.finish(offer_.sha256)) return finishUpdate(FirmwareUpdateResult::Failed);
    if (!sink_.activate(offer_.version)) return finishUpdate(FirmwareUpdateResult::Failed);
    active_ = false;
    return FirmwareUpdateResult::ReadyToReboot;
  }

 private:
  enum class Phase { ManifestHeaders, ManifestBody, ImageHeaders, ImageBody };

  void resetTransfer(size_t size) {
    requestSize_ = size;
    sent_ = bodyUsed_ = bodyLength_ = 0;
    connected_ = false;
    active_ = true;
    start_ = idle_ = port_.now();
    manifestHeaders_.reset();
    imageHeaders_.reset();
  }

  bool closeSocket() {
    if (!tcpOpen_) return true;
    tcpOpen_ = false;
    return port_.finishTcp();
  }

  FirmwareCheckResult finishCheck(FirmwareCheckResult result) {
    active_ = false;
    if (!closeSocket()) return FirmwareCheckResult::InvariantFailure;
    return result;
  }

  FirmwareUpdateResult finishUpdate(FirmwareUpdateResult result) {
    active_ = false;
    if (result != FirmwareUpdateResult::ReadyToReboot) sink_.abort();
    if (!closeSocket()) return FirmwareUpdateResult::InvariantFailure;
    return result;
  }

  Port& port_;
  const ResolvedHost& host_;
  OtaSink& sink_;
  char request_[512]{};
  char checkBody_[kOtaManifestBytes + 1]{};
  uint8_t otaBuffer_[4096]{};
  size_t requestSize_ = 0, sent_ = 0, bodyUsed_ = 0, bodyLength_ = 0;
  uint32_t start_ = 0, idle_ = 0;
  bool active_ = false, connected_ = false, tcpOpen_ = false;
  Phase phase_ = Phase::ManifestHeaders;
  ManifestHeaderParser manifestHeaders_;
  ImageHeaderParser imageHeaders_;
  FirmwareOffer offer_{};
};
}  // namespace eink::network_progress
```

The image request is sent once; the manifest request is sent once. `tcpOpen_` is set
only after a successful/pending `beginTcp`; `finishCheck`/`finishUpdate` close exactly
once. `finishUpdate` calls `sink.abort()` on every failure (safe when the sink already
finished). The success path closes the socket before `sink.finish`/`activate`.

```cpp
#pragma once
#include <Arduino.h>
#include <esp_ota_ops.h>
#include <mbedtls/sha256.h>
#include "ota.h"

namespace eink::network_progress {
class EspOtaSink final : public OtaSink {
 public:
  bool begin(size_t size) override {
    if (active_) return false;
    partition_ = esp_ota_get_next_update_partition(nullptr);
    if (!partition_ || size == 0 || size > partition_->size) return false;
    if (esp_ota_begin(partition_, size, &handle_) != ESP_OK) return false;
    mbedtls_sha256_init(&sha_);
    if (mbedtls_sha256_starts_ret(&sha_, 0) != 0) {
      esp_ota_abort(handle_);
      mbedtls_sha256_free(&sha_);
      return false;
    }
    active_ = true;
    return true;
  }
  bool write(const uint8_t* data, size_t size) override {
    return active_ && esp_ota_write(handle_, data, size) == ESP_OK &&
      mbedtls_sha256_update_ret(&sha_, data, size) == 0;
  }
  bool finish(const char* expected) override {
    if (!active_ || !expected) return false;
    active_ = false;
    const bool imageOk = esp_ota_end(handle_) == ESP_OK;
    unsigned char digest[32]{};
    const bool hashOk = mbedtls_sha256_finish_ret(&sha_, digest) == 0;
    mbedtls_sha256_free(&sha_);
    if (!imageOk || !hashOk) return false;
    constexpr char hex[] = "0123456789abcdef";
    char actual[65]{};
    for (unsigned i = 0; i < 32; ++i) {
      actual[i * 2] = hex[digest[i] >> 4];
      actual[i * 2 + 1] = hex[digest[i] & 15];
    }
    return std::strcmp(actual, expected) == 0;
  }
  bool activate(const char* version) override {
    if (!partition_ || !version || esp_ota_set_boot_partition(partition_) != ESP_OK) return false;
    // Serial marker required by the spec immediately before the reboot.
    Serial.printf("NETWORK_OTA_READY version=%s\n", version);
    return true;
  }
  void abort() override {
    if (active_) { esp_ota_abort(handle_); active_ = false; }
    mbedtls_sha256_free(&sha_);
  }
 private:
  const esp_partition_t* partition_ = nullptr;
  esp_ota_handle_t handle_ = 0;
  mbedtls_sha256_context sha_{};
  bool active_ = false;
};
}  // namespace eink::network_progress
```

`finish` calls `esp_ota_end` which frees the handle; `abort` is only called while
`active_`. If `esp_ota_end` fails, no abort is attempted. `activate` must be called
only after `finish` returned true.

```js
export function formatBytes(size) {
  if (!Number.isFinite(size) || size <= 0) {
    return "--";
  }
  return `${Math.ceil(size / 1024)} KiB`;
}

export function shortSha(value) {
  if (typeof value !== "string" || value.length === 0) {
    return "—";
  }
  return `${value.slice(0, 12)}…`;
}

export function firmwareView(status) {
  if (!status) {
    return {state: "unknown", label: "固件状态未知", canArm: false, canDisarm: false};
  }
  if (!status.configured) {
    return {state: "unconfigured", label: "Host 未配置固件", canArm: false, canDisarm: false};
  }
  if (status.armed) {
    return {
      state: "armed",
      label: `已武装 ${status.version}，等待设备取件`,
      canArm: false,
      canDisarm: true,
    };
  }
  if (status.served_at) {
    return {
      state: "served",
      label: "已发送固件，等待设备版本上报",
      canArm: true,
      canDisarm: false,
    };
  }
  if (status.device_version && status.device_version === status.version) {
    return {state: "current", label: "设备已是目标版本", canArm: false, canDisarm: false};
  }
  return {state: "ready", label: "可以准备升级", canArm: true, canDisarm: false};
}

export function confirmationText(status) {
  return `将允许设备下载并安装 ${status.version}，设备会重启。确认继续？`;
}
```

```js
function renderFirmware() {
  const view = firmwareView(firmwareFailed ? null : firmware);
  elements.firmwareVersion.textContent = firmwareFailed || !firmware?.configured
    ? "--" : firmware.version || "--";
  elements.firmwareSize.textContent = firmwareFailed ? "--" : formatBytes(firmware?.size);
  elements.firmwareSha.textContent = firmwareFailed ? "--" : shortSha(firmware?.sha256 || "");
  elements.firmwareDevice.textContent = firmwareFailed ? "UNKNOWN" : firmware?.device_version || "--";
  elements.firmwareState.textContent = view.label;
  elements.firmwareState.dataset.tone = view.state === "ready" || view.state === "current"
    ? "ok" : view.state === "unknown" || view.state === "unconfigured" ? "error" : "";
  elements.firmwareArm.disabled = !view.canArm;
  elements.firmwareDisarm.disabled = !view.canDisarm;
  elements.firmwareMessage.textContent = firmwareFailed
    ? "固件状态读取失败；在线管理不受影响。"
    : "";
  elements.firmwareMessage.dataset.tone = firmwareFailed ? "error" : "";
}

async function loadFirmware() {
  try {
    const response = await fetch("/api/device/firmware/status", {cache: "no-store"});
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    firmware = await response.json();
    firmwareFailed = false;
  } catch {
    firmware = null;
    firmwareFailed = true;
  }
  renderFirmware();
}

async function firmwareAction(path) {
  elements.firmwareArm.disabled = true;
  elements.firmwareDisarm.disabled = true;
  try {
    const response = await fetch(path, {method: "POST"});
    const body = await response.json().catch(() => ({}));
    if (!response.ok) {
      throw new Error(operatorErrorMessage(body.detail, `HTTP ${response.status}`));
    }
    firmware = body;
    firmwareFailed = false;
    renderFirmware();
    elements.firmwareMessage.textContent = path.endsWith("/arm")
      ? "已武装。设备下一次轮询会取件；失败后需重新武装。"
      : "已取消升级。";
    elements.firmwareMessage.dataset.tone = "ok";
  } catch (error) {
    renderFirmware();
    elements.firmwareMessage.textContent = `操作失败：${error.message}`;
    elements.firmwareMessage.dataset.tone = "error";
  }
}
```
